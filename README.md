# 🏎️ Mirza Horizon Legends

### Cross-Platform 3D Racing Game

Mirza Horizon Legends is a browser-based 3D racing game built with HTML5, JavaScript, and Three.js. Designed for both desktop and mobile devices, the game delivers smooth gameplay, responsive controls, and an immersive racing experience directly in the browser.

No installation required — simply open the game and start racing.
